🎨 Design Specifications

  • Color Scheme: Dark background (#0a0a0a) with neon green accents (#00ff41)
  • Typography: Segoe UI, JetBrains Mono, Courier New monospace stack
  • Spacing: Consistent padding (2rem) and margins throughout
  • Borders: Subtle 1px borders (#2a2a2a) with 4px accent left borders
  • Animations: Smooth transitions (0.3s) with ease timing functions
  • Shadows: Subtle glows on hover (0 0 20px rgba(0, 255, 65, 0.15))

🔧 Customization Guide

  • Personal Info: Edit name, email, and social links in HTML files
  • Projects: Update project cards in index.html with your projects
  • Repositories: Modify repositories array in script.js
  • Certificates: Update certificate cards in certificates.html
  • Colors: Change CSS variables in :root selector in style.css
  • Content: All text content can be easily updated in the HTML files

📱 Responsive Breakpoints

  • Desktop: 1200px and above - Full featured experience
  • Tablet: 768px to 1199px - Optimized layouts with adjusted grid
  • Mobile: Below 768px - Touch-friendly with stacked layouts
  • Small Mobile: Below 480px - Extra optimizations for small screens
